# Source and licensing

The extension's code, tools, protocol and preset documentation, and the new
features guide are provided under [MIT](LICENSE).

Grain mode's window shapes, stereo spread and grain stealing follow
Émilie Gillet's Mutable Instruments Beads (MIT); the extension implements
them in its own fixed-point code.

Rossum Electro-Music's Assimil8or software, its disassembly, and its
manuals are not included. Users obtain the official software separately.
The patch holds only this project's code and the addresses of the
instructions it replaces; where it reuses a stock routine, the patcher
copies that routine from the user's own file. Patched software files
contain Rossum's code and are local outputs, not release assets.

This is an independent, unofficial project for the Rossum Electro-Music
Assimil8or. It is not affiliated with or endorsed by Rossum Electro-Music.
